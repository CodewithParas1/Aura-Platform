# Aura | Cinematic Photography Portfolio 📸

**Aura** is a premium, high-performance photography portfolio and marketplace designed for visual storytellers. Built with a focus on cinematic aesthetics, smooth interactions, and artistic transitions.

## ✨ Core Features
- **Cinematic Hero**: Instant-load background imagery with elegant text reveals.
- **Grayscale-to-Color Reveal**: An interactive hover effect where photography reveals its full palette only upon engagement.
- **Horizontal "Film Strip" Scroll**: An immersive way to browse collections, mimicking a physical film strip.
- **Buttery Smooth Motion**: Powered by **Framer Motion** and **Lenis** for a refined user experience.
- **Responsive Mastery**: Fully optimized for all screen sizes, from mobile to ultra-wide displays.
- **AI-Powered Exploration** *(Work in Progress)*:
    - **Learning Assistant**: Explains photographic techniques and gear.
    - **Curator Agent**: Personalized discovery based on mood and style.

## 🛠 Tech Stack
- **Framework**: [Next.js 15](https://nextjs.org/) (App Router)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Animations**: [Framer Motion](https://www.framer.com/motion/)
- **Smooth Scroll**: [Lenis](https://lenis.darkroom.engineering/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **AI Engine**: [Google ADK](https://github.com/google/adk-python) (Python Backend)



## 🚀 Getting Started :-

### Prerequisites
- Node.js 18+
- Python 3.10+ (for AI Agents)

### Installation
1. **Clone the repository**:
   ```bash
   git clone https://github.com/CodewithParas1/Aura-Platform.git
   cd Aura-Platform
   ```
2. **Install dependencies**:
   ```bash
   npm install
   ```
3. **Run the development server**:
   ```bash
   npm run dev
   ```
4. **Visit the site**:
   Open [http://localhost:3000](http://localhost:3000) to see your portfolio in action.
